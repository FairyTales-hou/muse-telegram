# 貼紙功能規則（已上線 — 已寫進 hook 啟用）

## 用法
- 貼紙是像真人一樣反應情緒用的：同意、大笑、打招呼、賣萌。
- 偶爾用、點到為止，不要連發洗版。
- 廣告場合、套話場合永遠不用。

## 保險規則（硬線）
- 沒親眼看過本體的貼紙不准發。不准只看 emoji 標籤猜它畫什麼。
- 每張貼紙第一次用之前：先透過橋接 media 路徑把本體叫出來看清楚，並在筆記記下這張 file_id 畫的是什麼、適合什麼情境；之後再用就照筆記。
- 動畫貼紙（TGS）如果橋接給不了可檢視的預覽，一律不發。
- 看過、記好、才發。

## 貼圖紀律（2026-11-20 追加）
- 不主動丟貼圖刷存在感：沒人叫她、她不在那段對話裡，就安靜。
- 貼圖只能在她已參與的對話裡、作為回覆的一部分出現，不能單獨丟一張就走。
- 同一張貼圖一天最多發一次。
- 拿不準就不發。
